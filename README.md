# Mental-Health-Support-AI-Model
AI-powered mental health support chatbot using Streamlit, Sentence Transformers, FAISS, and Google Gemini.





An AI-powered mental health support chatbot designed to provide empathetic, context-aware responses using Natural Language Processing and Generative AI.

## Project Overview

The system accepts emotional text input and retrieves relevant information from mental-health reference documents to generate supportive responses.

## Technology Stack

- **Interface:** Streamlit
- **NLP & Embeddings:** Sentence Transformers
- **Vector Search:** FAISS
- **Generative AI:** Google Gemini Flash
- **Language:** Python

## System Workflow

1. User enters a message through the Streamlit interface.
2. Sentence Transformers converts text into vector embeddings.
3. FAISS retrieves relevant information from mental-health reference documents.
4. Gemini Flash generates a context-aware supportive response.
5. The response is displayed in the chatbot interface.

This project is an academic prototype for supportive conversation. It is not a diagnostic tool or a substitute for qualified mental-health professionals. Its responses may be inaccurate and should not be relied on for emergencies.
